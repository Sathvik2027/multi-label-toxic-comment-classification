# Aggregated research results

Only reviewed aggregate numeric CSV/JSON tables from historical experiments were copied here. This directory intentionally excludes files containing row-level comment text (`errors_to_tag.csv`, raw LIME explanation table, etc.), probability matrices, full data splits, and trained weights.

To verify run provenance see `registry.csv`, `preprocessing_summary.json`, `final_config.json`, and the numbered notebooks.

The results do not constitute a new independent run. Phase-2 outputs should be added only after they are executed and reviewed for raw comment text and test-set reuse.
